# Laser: settings and safety

## Operations

- **Laser: Vector (no offset / path inside / path outside)**: the laser follows the line; the beam is switched on for each outline and off after it.
- **Laser: raster fill (Beta)**: fills an area with lines. Experimental.

The laser program has **no Z moves**: you set the focus height by hand before starting. Power is written as an **S value** (scale 0 to 1000); the default power is 100 % (S1000), which is a lot.

## Before the first test

1. Lower the power in the operation to a small value first (for example 10 to 20 %) and raise it in steps on scrap.
2. Check the focus distance with the machine off.
3. Wear laser goggles that match the wavelength (the 450 nm blue modules need protection rated OD 5 or more). Both modules of this machine are **class 4**: the beam is dangerous to eyes and skin, also when reflected.
4. Keep a non-flammable surface under the work, never leave the machine running unattended, and have a fire extinguisher at hand.
5. The 50 W-labelled module needs its own power supply; see the project notes before connecting it.

> The default power and the S scale are starting points, not tested values. Test on scrap with the lowest power that marks the material.
